Quiet by default

Trustworthy numbers

The same figures your Mac reports.

MacosPanel reads the kernel directly — host_statistics64 for memory and sysctl for swap — instead of parsing shell output. Memory usage follows the same definition as Activity Monitor, so the numbers agree.

  • Used = App + Wired + Compressed. Cached files are excluded, exactly like Activity Monitor. Free is what is actually left.
  • Disk free matches Finder. It uses volumeAvailableCapacityForImportantUsage, so purgeable space counts as available.
  • No helpers, no sudo, no polling scripts. A single signed app with a menu bar item.

Install

Running in under a minute.

macOS 14 Sonoma or newer. The app is ad-hoc signed; if Gatekeeper complains, right-click it and choose Open.

  1. 1
    Download the app

    Grab MacosPanel.app from the latest release on GitHub.

  2. 2
    Move it to Applications

    Drag it into /Applications so login items work reliably.

  3. 3
    Launch and pin it

    Open it once. A menu bar item appears — enable Launch at Login from the gear menu.

From source 
# requires Xcode command line tools
git clone https://github.com/403access/macos-panel.git
cd macos-panel
./build.sh

cp -R build/MacosPanel.app /Applications/
open /Applications/MacosPanel.app

Builds with Swift Package Manager in a few seconds. No Xcode project needed.
